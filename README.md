## 編輯方式

- 每個主題的內容都在該資料夾的 `.md` 檔，`index.html` 只負責顯示，不用改。
- 標題層級 `#`、`##`、`###` 是心智圖的分支，`-` 清單是葉節點。
- 慣例：
  - `延伸問題：` 開頭是還要研究的問題
  - `來源：` 開頭放參考連結，例如 `- 來源：[標題](https://...)`
- 本機預覽：VS Code 安裝「Markmap」擴充功能，開啟 `.md` 後點右上角的 Markmap 圖示。

## 協作

1. 在 GitHub 上把協作者加進 repo（Settings → Collaborators）。
2. 修改 `.md` 後 commit 並發 Pull Request，或直接在 GitHub 網頁上編輯。
