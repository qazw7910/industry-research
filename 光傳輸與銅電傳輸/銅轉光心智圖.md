# 為何業界從銅電傳輸轉向光電傳輸？

- 每一代資料速率約翻倍，銅的損耗隨頻率快速上升，可用距離縮短、補償電路功耗增加
- AI 叢集讓連線的數量與距離暴增；光纖損耗幾乎與速率無關，產業因此把「光」往晶片推近
- 結論：不是全面取代，而是「短距離用銅、其餘用光」的分界線一直往晶片內縮
- 延伸問題：光與銅的分界線下一步停在機櫃之間、機櫃之內，還是封裝之內？

## 銅的物理瓶頸

- 延伸問題：224G 之後的 448G/lane，銅還有沒有可行方案？

### 趨膚效應與介電損耗

- 頻率越高，電流越集中在導體表面，有效截面變小、電阻上升
- 趨膚效應損耗約與 √f 成正比；介電損耗約與 f 成正比
- 112G PAM4 奈奎斯特頻率約 28 GHz，224G 約 56 GHz
- 延伸問題：更低損耗板材（Megtron 7/8 等級）能延後多少？
- 延伸問題：PAM4 與 NRZ 在損耗預算上差多少？

### 可用距離一直縮短

- 單通道速率每翻倍，被動銅纜距離約減半
- DAC：100G/lane 約 3 m；200G/lane 約 1–2 m（依線徑與規格而異）
- 距離不足以跨機櫃 → 只能改用主動元件或光
- 延伸問題：各速率世代 DAC 距離上限的實測數據？

### 訊號完整性

- 串擾、反射、阻抗不連續、連接器損耗吃掉損耗預算
- 需要 retimer 或 DSP 補償，銅鏈路不再「零功耗」
- 連接器與過孔（via）在高頻下成為主要損耗點
- 延伸問題：SerDes 等化能力（CTLE、DFE）還能進步多少？

### 實體與空間限制

- 高速銅纜要更粗才能降損耗，與密度需求衝突
- 線徑、重量、彎曲半徑、散熱氣流都是限制
- NVIDIA GB200 NVL72 機櫃內約 5,000 條銅纜（NVIDIA 公開說法）
- 延伸問題：機櫃線材重量與冷卻設計的關係？

## 需求驅動：AI 與資料中心

- 延伸問題：以推論為主的叢集，光的需求比例會跟訓練一樣嗎？

### 交換器頻寬每約 2 年翻倍

- 12.8T → 25.6T → 51.2T → 102.4T
- 102.4T 世代（如 Broadcom Tomahawk 6）使用 200G/lane SerDes
- 連接埠速率：400G → 800G → 1.6T → 3.2T
- 延伸問題：連接埠數量與單埠速率，哪個成長得比較快？

### AI 叢集規模擴大

- 訓練叢集從數千顆 GPU 擴大到十萬顆以上
- scale-out 跨機櫃、跨機房，距離數十公尺到數公里，只能用光
- 多層 Fat-tree / Clos 架構，每多一層就多一批光模組
- 延伸問題：跨資料中心訓練（multi-site）對長距光通訊的影響？

### Scale-up 網路

- GPU 之間高頻寬、低延遲互聯（如 NVLink）
- 目前機櫃內用銅；要擴大到多機櫃就需要光
- 對延遲與功耗極度敏感，是光的下一個大市場
- 延伸問題：NVLink、UALink 各自的光化時程？

### GPU 對光模組的比例

- 取決於網路層數、拓撲與連接埠速率
- 常見估算每顆 GPU 對應 2–3 顆以上 800G 等級光模組，架構不同差異很大
- 延伸問題：自研 ASIC 與 GPU 叢集的比例差異？

## 功耗與成本

- 資料中心瓶頸已變成電力，pJ/bit 成為關鍵指標
- 延伸問題：光互連功耗佔整個 AI 叢集功耗的比例？

### pJ/bit 指標

- 每傳輸 1 bit 消耗的能量
- 長距離銅鏈路需要 retimer/DSP，pJ/bit 隨速率上升
- 光鏈路能耗主要來自 DSP、雷射驅動與光電轉換

### 可插拔光模組的功耗

- 800G 模組約 13–16 W
- 1.6T 模組約 20–30 W（依設計而異）
- DSP 佔模組功耗相當大的比例
- 延伸問題：萬卡叢集的光模組總功耗大概多少？

### CPO 的節能潛力

- 光引擎放在晶片旁，電訊號只走極短距離，省掉大部分 DSP 與驅動功耗
- NVIDIA 宣稱其矽光子 CPO 交換器比可插拔方案省電約 3.5 倍
- 減少雷射數量與元件數

### 成本 $/Gbps

- 短距離銅仍最便宜
- 光的成本靠量產規模與矽光子整合持續下降
- 延伸問題：光與銅的 $/Gbps 交叉點落在幾公尺？

## 技術演進：光往晶片靠近

- 光電轉換點越來越靠近運算晶片，縮短電訊號距離
- 延伸問題：每一步演進犧牲了什麼（可維護性、互通性、成本）？

### 可插拔光模組

- QSFP-DD、OSFP，插在交換器面板，現階段主流
- 優點：易維修、生態成熟、多家供應商
- 缺點：電訊號從晶片走到面板，需 DSP 補償

### LPO / LRO 線性驅動

- LPO 拿掉 DSP、LRO 保留一半，由主晶片 SerDes 直接驅動
- 省功耗、降延遲、降成本
- 挑戰：互通性與鏈路預算
- 延伸問題：LPO 在 200G/lane 世代還可行嗎？

### NPO 近封裝光學

- 光引擎放在主機板上靠近晶片，不在同一封裝內，屬過渡方案

### CPO 共同封裝光學

- 光引擎與交換器 / GPU 晶片封裝在一起，演進主線
- Broadcom：Bailly（51.2T）、Davisson（102.4T）
- NVIDIA：Quantum-X / Spectrum-X Photonics（2025 GTC 發表）
- 台積電：COUPE 矽光子整合平台
- 延伸問題：CPO 何時從交換器延伸到 GPU 本身？

### 晶片級光 I/O

- 晶片直接用光對外溝通，取代封裝邊緣的電 I/O
- 代表廠商：Ayar Labs、Celestial AI、Lightmatter
- 延伸問題：光 I/O 會改變 chiplet 架構嗎？

### 關鍵元件

#### 矽光子 SiPh

- 用 CMOS 製程在矽上做波導、調變器、偵測器，可量產並與電路整合

#### 雷射光源

- EML、CW 雷射搭配矽光調變器、VCSEL（多模短距）
- 外部雷射源（ELS）讓雷射可插拔，解決 CPO 維修問題

#### 光纖與連接

- 光纖陣列（FAU）與晶片的對準、耦合是 CPO 量產難點

#### 調變格式

- PAM4 為資料中心主流；長距離用相干（coherent）技術

## 銅還在哪裡：共存而非取代

- 業界常說「能用銅就用銅，必須才用光」
- 延伸問題：銅在機櫃內還能撐幾個世代？

### 機櫃內短距 DAC

- 被動、不耗電、便宜、故障率低，2 公尺內首選

### AEC 主動電纜

- 線材兩端加 retimer，距離延長到約 5–7 m，光銅之間的過渡方案
- 代表廠商：Credo
- 延伸問題：AEC 市場會被 LPO 或 CPO 吃掉嗎？

### NVLink 銅背板

- NVL72 機櫃內 GPU 互聯選用銅
- NVIDIA 曾表示若改用光模組，每機櫃多耗約 20 kW
- 延伸問題：下一代更大機櫃是否仍能全用銅？

### 光的弱點

- 雷射可靠性、溫度敏感、光纖端面清潔、成本

## 挑戰與待解問題

### CPO 可維護性

- 光引擎壞了不能像模組直接換，可能要換整片板子
- 對策：外部可插拔雷射源，把最易壞的元件移出封裝

### 良率與測試

- 光電共封裝提高封裝良率與測試難度，需晶圓級光學測試

### 熱管理

- 雷射對溫度敏感，卻要放在高功耗運算晶片旁

### 標準與生態系

- IEEE 802.3dj（200G/lane 乙太網路）、OIF CEI-224G
- 延伸問題：CPO 會不會造成供應商綁定？

## 時間軸

- 2026 年以後為預期

### 2019–2021：400G

- 400G 可插拔模組起量；12.8T / 25.6T 交換器

### 2023–2024：800G

- AI 帶動 800G 大量出貨；51.2T 交換器；LPO 開始被討論

### 2025：1.6T 與 CPO 發表

- 1.6T 起量；102.4T 交換器；NVIDIA 與 Broadcom 公布 CPO 交換器

### 2026：CPO 開始出貨

- CPO 交換器進入資料中心部署（以各廠實際出貨為準）

### 2027 之後（預期）

- 3.2T、400G/lane 世代；scale-up 互聯開始光化
